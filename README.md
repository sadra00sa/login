# Login Page

A modern and responsive login page built with **HTML5** and **CSS3**.

## Live Demo

[View Live Demo →](https://sadra00sa.github.io/transparent-login/)

## Features

- Responsive design
- Glassmorphism-style login form
- Gradient background shapes
- Custom form styling
- Responsive layout for mobile devices

## Technologies

- HTML5
- CSS3
- Google Fonts (Poppins)

## Purpose

This project was created to practice HTML forms, CSS layout, positioning, gradients, responsive design, and modern UI styling.
